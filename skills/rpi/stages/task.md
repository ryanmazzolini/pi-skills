# Task stage

Use for focused single-concern work where the full question/research/design/structure path would be overkill.

## Rules

- Still write durable context when the work may span sessions.
- Keep the plan slim.
- Prefer direct implementation when risk is low and scope is clear.

## Output

Create or update a workflow-local `plan.md` with Goal, Approach, Done, Remaining Intent, Verification, and Notes. Then implement using `stages/implement.md` if requested.
